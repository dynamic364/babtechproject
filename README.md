# Babtech Project

A student project built with React. The current app is a frontend prototype with Home, Services, Pricing, Contact, and Support pages.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in the folder containing `package.json`.
3. Install the project packages:

   ```powershell
   npm install
   ```

4. Start the development server:

   ```powershell
   npm start
   ```

   In PowerShell, if script execution blocks `npm`, use `npm.cmd install` and `npm.cmd start`.

5. Open http://localhost:3000.

This is a Create React App project, so use `npm start`; there is no `npm run dev` script.

## Current scope

The repository contains the website interface and client-side routes. The contact form and booking flow are not connected to a backend yet, so this should be presented as a frontend prototype rather than a complete MERN application.
